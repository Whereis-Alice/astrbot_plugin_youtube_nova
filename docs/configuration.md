# 配置说明

## 解析与触发

“YouTube 输出模式”控制文本和富媒体是否发送。自动解析开启时，消息中出现受支持的 YouTube 链接即可触发；也可以只保留“媒体解析”等关键词，或开启引用消息触发。

同一链接和同一用户的频率限制默认关闭。需要限制时设置最大次数和统计窗口，记录保存在插件自己的运行时目录。

## 视频体积、压缩与群文件

插件把三件事分开处理：

- “视频大小上限”是管理员允许下载的硬上限，默认 1000 MiB。
- “可发送视频体积上限”只决定能否作为普通视频消息发送，默认 48 MiB。
- “超限视频投递方式”决定最终仍超限的视频是退回封面，还是上传为 QQ 群文件。

“上传为群文件”使用标准 OneBot v11 `upload_group_file`，适用于 aiocqhttp 下的 NapCat、LLOneBot / LLBot、SnowLuma 等协议端，仅在 QQ 群聊中生效。私聊、不支持的适配器、缓存不可用或上传失败时不会把大文件伪装成普通视频；插件会保留信息、封面与明确的失败提示。

视频压缩是独立策略，顺序固定为“下载 -> 按策略压缩 -> 判断普通视频或群文件投递”。可以关闭、始终执行，或只在超过自定义阈值时执行。目标体积、编码器、预设、最大分辨率、最大帧率、固定视频/音频码率、CRF、重试次数、超时和附加 ffmpeg 参数均可配置。阈值或目标体积填 0 时优先跟随普通发送上限；固定码率或 CRF 模式只编码一轮，产物仍需满足目标体积，否则保留原文件并进入后续投递判断。

启用压缩或群文件后，yt-dlp 会在管理员硬上限内优先取得高质量源文件，再交给后处理；两者都关闭时才直接把普通发送上限作为选流预算。48 MiB 是针对 LLOneBot/QQ Highway 53 MiB 实测拒收边界预留波动后的保守值，并非 QQ 固定协议上限。

## 代理

先填写代理地址，再开启“YouTube 解析与下载使用代理”。YouTube 的 googlevideo 直链可能绑定取链时的出口，因此解析和下载必须走同一代理。支持 `http://`、`https://` 和运行环境可用的 SOCKS 代理形式。

代理地址属于部署配置，不应写入仓库。

## 卡片与文本

卡片提供一套 YouTube 仿站皮肤和极光、报章、测控、展陈、夜曲五套通用皮肤，并独立控制布局、深浅色、水印、原链接和热评。“跟随平台”在本插件中等同于 YouTube 皮肤；旧配置里的 B 站或 X 皮肤值会自动迁移到 YouTube。卡片模式决定卡片与文本同条发送、分开发送或仅发送卡片。

“仅卡片”仍会保留必要的失败或媒体跳过提示，避免视频未发送却没有任何说明。

## Cookie

Cookie 接受 Netscape `cookies.txt`、扩展导出的 JSON 数组，以及 `a=1; b=2` 请求头格式。运行时轮换状态写在插件数据目录，不读取旧插件的状态文件。

Cookie 是账号凭据，只应填入 AstrBot 面板。不要放进配置示例、日志、Issue 或 GitHub 提交。
